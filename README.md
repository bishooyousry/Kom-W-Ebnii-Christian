# قوم وابنِ — درس الإيجابية المسيحية (إعدادي)

## الملفات
- `قوم_وابنِ_درس_الإيجابية_إعدادي.pptx`: 15 سلايد مع شرح وتوقيت ومصادر في Speaker Notes لكل سلايد.
- `index.html`: لعبة «قرار يصنع فرقًا» — خمس مواقف تفاعلية، نتائج فورية، وتحدي 24 ساعة.

## نشر اللعبة على GitHub Pages
1. أنشئ GitHub repository جديدًا، مثل `qom-w-ebny`، واجعله Public.
2. ارفع `index.html` إلى جذر المستودع (root)، واحتفظ باسمه كما هو.
3. افتح **Settings > Pages > Build and deployment**، واختر **Deploy from a branch**، ثم `main` و `/ (root)`، واضغط Save.
4. افتح الرابط الذي سيظهر في صفحة Pages؛ غالبًا يكون `https://YOUR-USERNAME.github.io/qom-w-ebny/` (استبدل الاسم باسم حسابك الفعلي). لا يوجد رابط منشور فعلي قبل رفع الملف.
5. انسخ الرابط وضعه على سلايد اللعبة، أو أنشئ QR منه.

## خطة تيسير مختصرة
- العرض: نحو 45–50 دقيقة بحسب النقاش.
- اللعبة: 10–12 دقيقة (فردي أو ثنائي).
- إجمالي الزمن: نحو 55–65 دقيقة.
- بعد اللعبة ناقش: أي موقف كان أصعب؟ ومتى طلب المساعدة يكون إيجابية؟

## السلامة والخصوصية
اللعبة لا ترسل بيانات لأي خادم، ولا تطلب اسم الطالب، وتعمل دون مكتبات خارجية. جميع القرارات موجودة داخل الملف. لا تجعل النقاط تصنيفًا للأطفال. حالات الأذى والخطر تستلزم طلب مساعدة بالغ موثوق.

## مصادر كتابية
